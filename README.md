# 个人作品集

本仓库是个人作品集网页的源码 —— 纯静态单页站点，样式与脚本内联，无框架、无构建步骤、无外部 CDN 依赖，电脑与手机自适应。

站点同时部署在 Cloudflare Pages 与 GitHub Pages 两个平台，内容一致、互为备份。

## 访问地址

| 平台 | 网址 |
|---|---|
| Cloudflare Pages | <https://zouxunhao-portfolio.pages.dev/> |
| GitHub Pages | <https://wu-nai-a.github.io/portfolio/> |

## 说明

推送到 `main` 分支后，两个平台会自动部署更新，无需手动执行任何部署命令。详细流程见 [`info/部署与更新指南.md`](info/部署与更新指南.md)。
