## 更新与部署

本仓库推送到 `main` 分支后，两个站点会**自动部署**，无需手动执行任何部署命令：

```bash
git add -A
git commit -m "更新作品集"
git push origin main
```

| 平台 | 生效时间 | 说明 |
|---|---|---|
| Cloudflare Pages | 约 1~2 分钟 | 由 GitHub Actions 自动部署到正式网址 |
| GitHub Pages | 约 1 分钟 | GitHub 内置自动部署 |

完整流程、常见问题排查见 [`info/部署与更新指南.md`](info/部署与更新指南.md)。
