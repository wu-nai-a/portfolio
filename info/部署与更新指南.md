# 🔧 部署与更新指南

> 本指南说明作品集网站如何更新、如何重新部署。**普通更新只需 2 步：改文件 + 推送。**

---

## 一、日常更新（改内容 / 加作品 / 改联系方式）

### 方式 A：找 AI 助手帮你改（推荐）

把新作品素材（图片/视频）或要改的内容发给 AI 助手，让它完成：
1. 更新 `index.html`（增删板块、改文字）
2. 把新素材放进 `img/` 或 `video/`
3. 推送到 GitHub（自动同步到两个网站）

### 方式 B：自己手动改

1. **下载 / 克隆仓库**：
   ```bash
   git clone https://github.com/wu-nai-a/portfolio.git
   ```
2. **修改文件**：
   - 改网页内容 → 编辑 `index.html`
   - 加图片 → 放到 `img/`，在 `index.html` 里用 `<img src="img/xxx.jpg">` 引用
   - 加视频 → 放到 `video/`，在 `index.html` 里加视频卡片（参考现有视频卡片的写法）
3. **推送上线**：
   ```bash
   git add -A
   git commit -m "更新作品集"
   git push origin main
   ```
   > GitHub Pages 会自动更新（约 1 分钟生效）
   > Cloudflare Pages 需要重新部署：`npx wrangler pages deploy . --project-name zouxunhao-portfolio`（需 Cloudflare API 令牌）

---

## 二、重新部署（两个平台）

### GitHub Pages（自动）
推送到 `main` 分支后自动生效，无需其他操作。
管理后台：https://github.com/wu-nai-a/portfolio/settings/pages

### Cloudflare Pages（需手动或自动化）
```bash
# 需要 CLOUDFLARE_API_TOKEN 环境变量
npx wrangler pages deploy . --project-name zouxunhao-portfolio
```
管理后台：https://dash.cloudflare.com → Workers & Pages → zouxunhao-portfolio

## 三、素材要求

| 素材 | 建议规格 |
|---|---|
| 图片 | JPEG/PNG，单张 ≤ 500KB，宽度 ≥ 1200px 清晰度最佳 |
| 视频 | MP4 H.264，720p（1280px 宽），单个 ≤ 20MB，网页播放流畅 |
| 格式 | 中文文件名建议改成英文/拼音（如 v_fox.mp4），避免特殊字符 |

> 压缩工具参考：`ffmpeg -i 输入.mp4 -vf "scale='min(1280,iw)':-2" -c:v libx264 -preset veryfast -crf 28 -c:a aac -b:a 96k -movflags +faststart 输出.mp4`

## 四、注意事项

- **不要删除** `info/` 文件夹（本说明文档）
- 仓库是公开的，**不要在仓库里放隐私信息**（手机号、邮箱已在网页里展示，属有意公开）
- 修改后务必先本地预览 `index.html`（双击打开即可），确认无误再推送
- 若网页引用了新图片/视频但忘记上传文件，页面会显示空白，推送前检查 `img/`、`video/` 是否齐全
