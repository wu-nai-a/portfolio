## 🔧 自动部署是怎么跑的

```
git push origin main
        │
        ├─→ GitHub Pages 自动构建（约 1 分钟）→ wu-nai-a.github.io/portfolio/
        │
        └─→ GitHub Actions「部署到 Cloudflare Pages」
                ① 自检两个 Secret（缺失/填错/带空白都会中文报错）
                ② 校验 API 令牌有效性
                ③ 校验账户 ID 与 Pages 项目权限
                ④ 确保项目生产分支为 main
                ⑤ npx wrangler pages deploy
                ⑥ 校验本次是否为 production 部署
                        ↓
              zouxunhao-portfolio.pages.dev（约 1~2 分钟）
```

工作流文件：`.github/workflows/pages-deploy.yml`
所有失败原因都会以中文 annotation 显示在运行页顶部，不用翻日志。
