## ⏳ 待办

### 1. 配置 Cloudflare 自动部署（GitHub Actions）——进行中

- **现状**：Cloudflare 项目 `zouxunhao-portfolio` 是 `npx wrangler pages deploy` 手动上传创建的 **Direct Upload** 项目，推送代码不会自动部署
- **决策**：**不采用** Cloudflare 后台的 Git 集成。因为 Direct Upload 项目无法转换，只能删项目重建，而 `zouxunhao-portfolio.pages.dev` 已印在简历上，删除会导致中断并有子域名被抢注的风险
- **方案**：改用 GitHub Actions（`.github/workflows/pages-deploy.yml`），推送 `main` 由 GitHub 自动调用 Cloudflare 接口部署。**项目、网址、部署记录全部不变**
- **待你在浏览器/终端完成 3 件事**：
  1. 创建 Cloudflare API 令牌（权限 `Account → Cloudflare Pages → Edit`）
  2. 拿到 Cloudflare Account ID
  3. 在 https://github.com/wu-nai-a/portfolio/settings/secrets/actions 添加 `CLOUDFLARE_API_TOKEN` 和 `CLOUDFLARE_ACCOUNT_ID`
  4. 推送 `main`，并在 https://github.com/wu-nai-a/portfolio/actions 确认运行成功
- **完整步骤**：见 `info/部署与更新指南.md` 第三节

- 说明：令牌仅用于首次上传；撤销不影响已上线的网站

### 4. 撤销 Cloudflare 旧部署令牌（安全建议）

- ⚠️ **新令牌 `portfolio-pages-deploy` 要保留**，它存在 GitHub Secrets 里，是自动部署的凭据
